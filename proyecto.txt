# ============================================================
#  PATITAS DE LANA · Documentación del proyecto
# ============================================================

Tienda web de amigurumis tejidos a mano (Chile).
Proyecto estático: HTML + CSS + JavaScript vanilla (sin framework ni build).
Backend: Supabase (base de datos de productos + autenticación de admin).

------------------------------------------------------------
  AUTORA
------------------------------------------------------------
Yantil Gómez — creadora de Patitas de Lana.
Marca de amigurumis 100% hechos a mano y personalizables.

------------------------------------------------------------
  ESTADO ACTUAL
------------------------------------------------------------
Sitio en desarrollo (front-end). El pago es SIMULADO (no cobra de verdad).
La integración de pago real (Transbank / Mercado Pago) requerirá backend
y queda pendiente fuera de este alcance.

------------------------------------------------------------
  ESTRUCTURA DE ARCHIVOS
------------------------------------------------------------
index.html          Home: selector de "Modo de Compra" (Stock vs Personalizado).
catalogo.html       Catálogo en stock (grid dinámico desde Supabase).
personalizados.html Formulario de encargo -> abre WhatsApp.
papeleria.html      Sección de papelería (productos estáticos).
nosotros.html       Historia de la marca.
contacto.html       Información de contacto.
admin.html          Panel de administración (CRUD de productos).
admin.js            Lógica del panel admin (login + CRUD + vista previa).
script.js           Carrito, drawer, modal de pago (simulado), menú móvil, toast.
style.css           Estilos globales + variables de diseño (paleta pastel).

css/
  catalog.css       Estilos del catálogo + hero.
  admin.css         Estilos del panel admin.

js/
  supabase.js       Cliente Supabase + funciones CRUD y auth.
  catalog.js        Render del catálogo desde Supabase.

------------------------------------------------------------
  FLUJO PRINCIPAL
------------------------------------------------------------
1. index.html -> dos tarjetas de modo: navega a catalogo.html o personalizados.html.
2. catalogo.html -> js/catalog.js trae productos de Supabase y pinta tarjetas.
   Botón "Añadir al carrito" llama a window.addToCart(id).
3. Carrito (script.js) -> guarda en localStorage ("patitas-de-lana-cart"),
   drawer lateral, modal de pago SIMULADO (Webpay / Redcompra / Transbank / MercadoPago).
4. Papelería -> productos estáticos registrados en script.js (STATIC_PRODUCTS).
5. Personalizados -> formulario que arma un mensaje y lo abre en wa.me (WhatsApp).
6. Admin (admin.html + admin.js) -> login con Supabase Auth, CRUD de productos.

------------------------------------------------------------
  CONFIGURACIÓN (Supabase)
------------------------------------------------------------
Editar js/supabase.js:
  - supabaseUrl
  - supabaseKey  (publishable key; revisar políticas RLS en Supabase)
Tabla usada: "productos"
Columnas: id, name, desc_text, price, stock, emoji, image_url, category.
